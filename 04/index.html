디지털 생명체의 삼위일체

웹 페이지는 브라우저라는 환경 속에서 살아 숨 쉬는 '디지털 생명체'와 같습니다. 이 생명체를 구성하는 세 가지 핵심 요소를 인체 구조에 비유하여 그 본질을 꿰뚫어 봅시다.

01

HTML: 웹의 뼈대와 내장 기관

Structure Scope
<head> (보이지 않는 사고 영역)

브라우저가 페이지를 렌더링하기 전 처리해야 할 사전 정보(메타데이터, 스타일 링크, 스크립트 등)를 담는 영역입니다.

Viewport Scope
<body> (보이는 외형 영역)

사용자가 직접 보고 상호작용하는 모든 시각적 콘텐츠(텍스트, 이미지, 영상)가 배치되는 핵심 영역입니다.

Semantic Logic

시맨틱 마크업의 가치

의미 있는 태그를 사용하면 검색 엔진 최적화(SEO)에서 유리하며, 장애를 가진 사용자를 위한 웹 접근성을 보장합니다.

<header> 얼굴과 머리말
<nav> 신경망 경로
<main> 핵심 장기
<article> 독립 신체 기관
02

CSS: 웹의 피부와 의상

Priority Calculation

명시도 점수 (Specificity)

여러 스타일이 충돌할 때, 브라우저는 수학적 점수 체계에 따라 우선순위를 결정합니다.

선택자 유형 점수(ID-Class-Type) 비유
Inline Style (1, 0, 0, 0) 태그에 새긴 지울 수 없는 문신
ID Selector (0, 1, 0, 0) 오직 한 사람만을 지칭하는 이름표
Class Selector (0, 0, 1, 0) 특정 그룹이 입는 유니폼
Element Selector (0, 0, 0, 1) '사람' 종족 전체의 특징
Modern Flow

현대적 레이아웃

Flexbox (1차원)

직선(행/열) 중심 정렬 (메뉴 바 등)

Grid (2차원)

가로와 세로 동시 제어 (대시보드 등)

Box Sizing Engine

박스 모델 (Box Model)

CONTENT (본체)
Border / Padding
Margin (사회적 거리)

현대 개발자들은 레이아웃 계산의 편의를 위해 box-sizing: border-box;를 기본으로 사용합니다.

03

JavaScript: 신경계와 뇌

Document Interface

DOM (문서 객체 모델)

JavaScript는 브라우저가 생성한 DOM이라는 '신체 지도'를 통해 요소를 탐색합니다. 클릭이나 스크롤 같은 자극(이벤트)이 감지되면, 이 지도를 참고하여 특정 UI의 근육을 움직이는 명령을 내립니다.

Memory Scope

메모리 저장 메커니즘

기본 자료형 (Primitive)

Stack 메모리에 실제 값을 직접 저장합니다. 작고 명확한 데이터(숫자, 문자 등)에 적합합니다.

참조 자료형 (Reference)

본체는 Heap에 저장하고 Stack에는 그 '주소(Pointer)'만 저장합니다. 복사 시 주소가 전달되므로 부수 효과를 주의해야 합니다.
